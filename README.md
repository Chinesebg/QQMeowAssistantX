## UI 优化
**Material3风格**，同时提供第二套可切换 UI：**Miuix 风格整体界面 + AndroidLiquidGlass 风格底部悬浮玻璃按钮**。

第二套 UI 已迁移到 **Compose + top.yukonga.miuix.kmp** 技术栈，整体结构参考 [MiaoAssistant](https://github.com/mazha0309/MiaoAssistant)，包含 Miuix 页面组件、悬浮底栏与液态玻璃效果。

- **底部 Tab**：「主页」和「设置」
  - 主页：原控制面板
  - 设置：新增「主题颜色」「深色模式」「界面风格」「关于」「获取更新」「多语言（在做了）」
- **主题颜色**
- **界面风格**：Material Design / Miuix 一键切换


## 功能
- 自定义文本替换规则（`原词=替换词`，也支持 `→`，按顺序应用）
- 文本替换规则预设（一键填入「我=本喵 / 你=主人」）
- 断句追加（按标点分句，句末追加可自定义文本，默认“喵”）
- 句末随机颜文字（内置 50+ 个，可自定义）
- 处理模式：标点触发 / 实时处理
- 基于无障碍服务，仅作用于 QQ 输入框
- **增强功能**：新增混合和AI模式，可接入生成式人工智能模型，进行更深度的优化。

## 构建
```bash
./gradlew assembleDebug
```
产物：`app/build/outputs/apk/debug/app-debug.apk`

## 使用
1. 安装 APK（开启"允许未知来源"）
2. 打开应用 → 开启无障碍服务
 - _对于Android 15（SDK35）及以上版本的用户，需要在应用详情（根据品牌而异，部分机型如OPPO在应用权限）中右上角三点选择解除限制后，方能打开无障碍服务_

3. 配置替换规则 / 断句 / 颜文字 → 保存设置
4. 在 QQ 聊天中输入，触发规则自动改写
